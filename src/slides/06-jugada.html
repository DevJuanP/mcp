16 conexiones directas → 8 conexiones al protocolo N × M = 16  →  N + M = 8

Este es el momento “ajá” del deck. Pulsa el botón y deja que el contador baje de 16 a 8. No es magia: es un cambio de topología. Las apps hablan con un protocolo y los sistemas exponen un server para ese protocolo.

MCP no elimina la integración. La mueve: cada sistema sigue necesitando un server que sepa hablar con su API, su base de datos o sus archivos. Lo que desaparece es la multiplicación por cada app.

La fórmula N×M → N+M es una simplificación pedagógica. En la práctica hay auth, permisos y versiones; pero la diferencia de orden de magnitud es real.
