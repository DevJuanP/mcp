USB-C para la IA

La analogía oficial sirve para entender la idea en diez segundos. Después hay que soltarla: un conector no es un protocolo.

S1 · What is MCP? · docs oficiales

“Think of MCP like a USB-C port for AI applications. Just as USB-C provides a standardized way to connect electronic devices, MCP provides a standardized way to connect AI applications to external systems.”

Piensa en MCP como un puerto USB-C para aplicaciones de IA. Igual que USB-C ofrece una forma estandarizada de conectar dispositivos electrónicos, MCP ofrece una forma estandarizada de conectar aplicaciones de IA con sistemas externos.

! Es una analogía, no una especificación. USB-C estandariza pines y electricidad; MCP estandariza mensajes JSON-RPC, descubrimiento de capacidades y tres primitivas. Lo que se comparte es la idea de un conector común, no el diseño interno.

LO QUE ESTANDARIZA

Un formato de mensaje, un ciclo de descubrimiento, tres primitivas y dos transportes.

LO QUE NO ESTANDARIZA

Tu modelo, tu UI, tu lógica de negocio ni el diseño de tu API.

La analogía es útil para la intuición, pero conviene decir qué se pierde. USB-C es un estándar físico y eléctrico; MCP es un protocolo de mensajes. La parte que sí se transfiere es la idea de un contrato común que evita un cable distinto por dispositivo.
