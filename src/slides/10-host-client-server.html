LA REGLA

3 servers → 3 clients. Un server remoto puede atender muchos clients, pero cada client mantiene su propia conexión 1:1.

FIG. 10 — el client es un objeto del host, no un proceso ni una persona

La confusión más común es pensar que hay dos piezas: “la app” y “el server”. Hay tres. El host es la aplicación (Claude Desktop, VS Code, Cursor). El server es el programa que expone capacidades. El client es el objeto que el host crea para hablar con un server concreto.

La relación 1:1 es entre client y server. Un host con tres servers tiene tres clients. Eso da aislamiento: cada conexión tiene su ciclo de vida, sus capacidades y sus permisos.

Matiz importante: un server remoto puede atender a muchos clients de muchos hosts a la vez. La relación 1:1 es la conexión, no el proceso del server.
